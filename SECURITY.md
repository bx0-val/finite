# Security policy

Please report security issues privately using [GitHub's private vulnerability reporting](https://github.com/bx0-val/finite/security/advisories/new) rather than a public issue. You can expect a reply within a week.

Finite runs only on `x.com` and `twitter.com`, stores data only in local extension storage, and makes no network requests. Reports that show a way around any of those properties are especially welcome.
